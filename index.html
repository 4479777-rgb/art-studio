Frontend

Frontend development is based on three main programming languages: HTML, CSS, and JS.

HTML is responsible for the website's structure—text, images, links, headings, and video.

CSS handles styles, background colors, text, positioning, rounded corners, mobile responsiveness, sizing, and much more.

JavaScript handles interactivity; it allows for the creation of event listeners for user actions—such as clicks, hover effects, form submission validation, and conditional logic.

HTML consists of tags like `<a href=""></a>` (a link); the `href` attribute is required only for links.

You also need a class for these tags so you can target them individually in CSS; otherwise, if you apply styles directly to the tag itself, those styles would affect every instance of that tag. You define it like this, for example: `<a href="" class="link"></a>`.

You also need to link the CSS file in the HTML; this is done using the `` tag: `<link rel="stylesheet" href="style.css">` The file must be created and located in the same folder as the HTML file; I named mine `style.css`.

Also, if you are using Windows, you can download Visual Studio Code from Microsoft. After creating a file, simply type `!` and press Enter; this will automatically generate all the necessary HTML tags. I also recommend downloading the "Live Server" extension, which allows the site to update automatically without needing a manual refresh.

backend

The backend can be written in various languages, such as Python, C++, C#, C, Go, and assembly.

Unlike HTML, CSS, and JS, these languages ​​allow you to create not only websites or applications but also games.

Libraries are also created in these languages; these consist of ready-made functions—such as the `time` library—so you don't have to write them from scratch.to track code execution time

But there are also frameworks—which are essentially libraries designed for websites—that affect the site's file system.

I am learning to write applications using the Python Django framework.

The backend is primarily needed for the database to handle account creation, authorization, and authentication.

For example, with WhatsApp: when we send a message, it is saved in the database, and if we delete it, that database record is removed.

Also, when we create an account, it is saved in the database so that the account isn't deleted after you log out.

I’ve covered the most important points in this message, but there are also game engines—which are even more powerful than libraries since they are full-fledged applications. They come with so many built-in functions that a small game might require only 100 lines of code or less; for comparison, creating just one level of *Plants vs. Zombies* in Python using the Arcade library required me to write over 2,000 lines of code.
